## About JavaScript

JavaScript is a high-level, interpreted, single-threaded, dynamically typed language. It runs on both:

| Client-side (Browser) | Server-side (Node.js) |
|---|---|
| DOM, events, fetch API | Servers, databases, file system |
| `window`, `document`, `localStorage` | `fs`, `http`, `process`, `require` |
| React, Vue, Angular | Express.js, NestJS |

## Topics Covered

**Fundamentals**
- Variables: `var`, `let`, `const`
- Data types: primitive and non-primitive
- Operators, conditions, loops
- Functions: declaration, expression, arrow, default and rest parameters

**Core Concepts**
- Scope, hoisting, Temporal Dead Zone (TDZ)
- Closures
- `this` keyword, `call`, `apply`, `bind`
- Prototypes and inheritance
- Classes and OOP

**Data Handling**
- Arrays: `map`, `filter`, `reduce`, `find`, `some`, `every`, `slice`, `splice`
- Objects: `Object.keys`, `Object.values`, `Object.entries`
- Destructuring, spread, rest
- Strings and template literals

**Asynchronous JavaScript**
- Callbacks
- Promises
- `async` / `await`
- Event loop, microtask vs macrotask queue

**Browser and Modules**
- DOM manipulation and events
- Event bubbling, capturing, delegation
- ES Modules (`import` / `export`) and CommonJS (`require`)
- Error handling

## How to Run

**Clone the repository**
```bash
git clone https://github.com/divyanshugupta72688/<repo-name>.git
cd <repo-name>
```

**Run in Node.js**
```bash
node --version
node 01-basics/variables.js
```

**Run in Browser**
1. Open the `.html` file in any browser, or use the VS Code Live Server extension.
2. Open DevTools (`F12`) and check the Console tab.
